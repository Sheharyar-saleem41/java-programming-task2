# Number Game 🎮

## 📌 Description

**Number Game** is a simple Java console-based game developed as part of my **Java Programming Internship at Decode Labs**.

The game allows the user to guess a randomly generated number. After each guess, the program provides feedback to help the user reach the correct answer.

## 🛠️ Technologies Used

* Java
* Java Scanner
* Conditional Statements
* Loops
* Random Number Generation

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

### 2. Open the project

Open the project in any Java-supported IDE, such as:

* NetBeans
* IntelliJ IDEA
* Eclipse
* VS Code

### 3. Compile the program

```bash
javac NumberGame.java
```

### 4. Run the program

```bash
java NumberGame
```

## 🎯 Features

* Generates a random number
* Takes the user's guess
* Provides feedback on the guess
* Allows the user to continue guessing
* Simple and beginner-friendly console interface
